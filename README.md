# org_bot — Телеграм-бот для замены англицизмов (YandexGPT)

Бот на Python (pyTelegramBotAPI) c YandexGPT (через OpenAI-совместимый Responses API). Анализирует входящий текст, находит англицизмы/заимствования и предлагает природные русские альтернативы, учитывая контекст и стиль. Поддерживает инлайн-режим и ЛС.

## Быстрый старт
1. Скопируйте `.env.example` в `.env` и заполните токены.
2. Установите зависимости.
3. Запустите бота.

### Настройка окружения
Создайте `.env`:
```
copy .env.example .env
```
Заполните `TELEGRAM_TOKEN` и параметры Yandex: `YANDEX_API_KEY` (или `YANDEX_IAM_TOKEN`), `YANDEX_FOLDER_ID`, `YANDEX_MODEL=yandexgpt-lite`.

### Установка зависимостей (Windows PowerShell)
```
python -m venv .venv
. .venv/Scripts/Activate.ps1
pip install -r requirements.txt
```

### Запуск
```
python -m src.bot
```

## Функции
- Контекстный анализ; не меняет устойчивые выражения и имена собственные (делегируется LLM).
- Несколько вариантов замен.
- Обучаемость: сохраняет пользовательские запросы и локальный словарь в JSON (`data/`).
- Rate limit и простая фильтрация ссылок.
- Инлайн-режим и ответы в ЛС.

## Настройка стиля
Команда /style открывает выбор: auto, strict, conversational, formal. Предпочтение сохраняется в `data/user_settings.json`.

## LLM-провайдер
- YandexGPT (OpenAI-совместимый Responses API)

## JSON-хранилище
- `user_requests.json` — последние 50 запросов на пользователя
- `rate_limits.json` — счётчики лимитов
- `user_settings.json` — предпочтения по стилю
